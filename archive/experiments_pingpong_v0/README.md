# 三全向轮底盘、机械臂和球拍：腕部 D405 视觉闭环

在本目录运行。默认主窗口为可旋转、缩放的全局视角，右下角显示控制器实际使用的 D405 RGB 图像。改变观察窗口不会改变控制器的相机。

```bash
PY="$HOME/Github/Panthera-HT_pingpong-balance/.venv/bin/python"
"$PY" balance.py view
MUJOCO_GL=egl LP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 "$PY" balance.py train
MUJOCO_GL=egl LP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 "$PY" balance.py eval
```

沿用参考项目 recovery_v1 的腕部固定安装变换、球拍与球的几何、128×96 对齐彩色和深度图、58° 垂直视场、30 Hz 策略频率和两帧指令延迟。沿用其橙球检测与球面拟合。没有使用原项目的神经网络权重；本任务重新训练了一个四参数反馈策略。

`SensorPolicy` 不持有仿真对象。它接收从 RGB-D 拟合的相机坐标（丢失为 None）、轮编码器和固定标定。相机到拍面的刚性变换来自 CAD；球速取视觉差分；底盘位移取轮编码器里程计。短时遮挡最多外推三帧，随后撤销球误差并使拍面回水平。电机伺服使用关节与轮编码器的位置和速度，以及从 CAD 零负载球状态独立计算的名义重力补偿。没有外部定位、接触开关、球真值、底盘真值或仿真相机世界位姿进入策略。真实使用前需测量安装外参、深度对齐和传感器/执行延迟。

`train` 通过 RGB-D 估计的拍心误差和丢检惩罚选取增益，8 组候选，每组 3 个种子、每个 3 秒。`eval` 独立使用种子 1000–1019，每次 20 秒，初始偏心 12–45 mm、水平速度 0.015–0.09 m/s。评测器用仿真真值独立核查：球没有跌落，且最后 1 秒每个采样点保持接触、与拍心距离小于 20 mm。仿真器在物理演算和渲染中使用世界状态；这些数据不送入控制器。结果记录在 `d405_evaluation.json`，不涵盖自由落球、突发强推或实机工况。`legacy_oracle` 仅存旧的真值对照记录，程序不加载它们。

机械臂来源：`reference_arm/description/urdf/Panthera-HT_description_V1.1.0_follower.urdf`，连同全部视觉与碰撞网格一起迁移。`reference_arm/convert.py` 负责转换。整个机械臂根部接在原底盘安装位置，推理相机挂在 URDF 的 `camera_link` 上，仅进行光学坐标约定转换。相机外壳、支架及惯量均来自该 URDF。旧 `d405_evaluation.json` 是迁移前模型的评测，不作为新模型成绩。

## PPO 协同策略

`train_ppo.py` 复用参考项目的 PPO 更新实现，训练 42 维传感器观测、9 维残差动作（3个轮速和6个关节目标位置）。在视觉反馈基线上学习修正，不是直接加载原固定底座权重。电机反馈力矩参与 actor 和 critic 输入。奖励来自视觉误差、电机功率估计和动作变化；丢检终止也来自视觉。环境在第2秒注入未告知策略的0.04 m/s水平球速扰动。RGB-D拟合结果加0.7 mm噪声和2%随机丢检；尚无真实深度误差校准。

```bash
MUJOCO_GL=egl LP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 "$PY" train_ppo.py --iterations 40
# 继续已有训练
MUJOCO_GL=egl LP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 "$PY" train_ppo.py --iterations 40 --resume
MUJOCO_GL=egl LP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 "$PY" eval_ppo.py
```

模型和逐轮日志存于 `ppo_run/`。`eval_ppo.py` 用未参与训练的种子比较基线和最新权重；评测允许仿真真值核验掉球，但这些真值不进入训练。训练产物需通过评估后再选为展示模型，默认 `balance.py view` 仍使用基线。

## 键盘底盘控制

运行 `view_ppo.py`，默认手动底盘模式：W/S 前后、A/D 左右、Q/E 逆时针/顺时针自转，均相对底盘自身坐标。松键减速停车，X将目标速度归零，M切换手动与PPO底盘控制；机械臂仍采用视觉策略。平移0.12 m/s、自转0.4 rad/s，带加速度限制。方向键保留推球。连续丢球时演示自动重开回合，R仍可手动重开；复位后需松开移动键再驾驶。PPO未训练持续遥控行驶时保球，移动中可能掉球。

`chassis_kinematics.py` 根据URDF轮心和轮轴给出逆解与编码器正解，左/右/后轮排列。设轮轴 a、驱动切向 t=(a_y,-a_x)、轮心(x,y)、半径r，则轮速=(t_x vx+t_y vy+(-t_x y+t_y x)wz)/r。三个轮子按相同比例限速，保留指令方向。此处半径使用模型值0.0654 m，实机需标定有效滚动半径和电机方向。

## 原单臂策略 + 键盘底盘

`"$PY" view_ppo.py --single-arm` 加载原项目 `d405_rgbd_recovery.pt` 第1500轮权重，42维原格式观测、6维关节增量动作、0.04 rad动作尺度、两帧延迟、3步动作历史。轮速仅来自键盘，禁用M切换PPO底盘。单臂输入只含RGB-D估计、机械臂编码器及动作历史；用独立运动学模型将相机点变换至底盘坐标，不读取浮动底座真值。原固定基座世界坐标语义变为底盘相对坐标，未经移动底座训练；不保证运动中保球。电机限幅保持启用。静止底盘20秒检查通过，末端拍心误差约2.4 mm。


## 丢球自动重开

`view_ppo.py --single-arm` 中，D405 连续12帧（0.4秒）未检测到球，或者连续6帧检测到球超出恢复区域（拍面内距中心超过0.20米，或低于拍面0.08米），会自动结束并重开这一回合。短暂漏检不会重开。判定仅用RGB-D测量和机械臂编码器正解，不读取球或底盘世界真值。画面显示回合编号、自动重开开关状态及最近原因。

复位会将机器人和球放回该演示的初始状态，并清空球速估计、目标位置、动作历史、延迟队列、外部推力和键盘速度；不是策略自行把掉落球捡回。相机观察视角保留，D405输入重新采集。松开移动键后可继续驾驶。演示没有因为到达训练时长而定时复位，只对失败或按R重开。

`check_episode_restart.py` 验证短暂遮挡不会重开、两次实际出视野均自动复位、历史数据清空及后续推理继续。


## 鼠标外力

全局视角中双击球、机械臂连杆或底盘选中；也可直接按住Ctrl点击目标开始拖拽。

- Ctrl + 鼠标右键拖拽：平移施力。
- Ctrl + 鼠标左键拖拽：施加力矩。
- 同时按Shift：切换水平移动/旋转方向。
- 松开鼠标或Ctrl、切换窗口、暂停或回合复位：撤销鼠标外力。

画面显示选中物体、合力(N)和力矩(Nm)。只有全局画面支持拾取，右下角D405图像不接受选中操作。不按Ctrl的拖拽继续控制观察视角，WASDQE仍控制底盘。

鼠标扰动使用MuJoCo弹簧施力，在每个物理子步更新 xfrc_applied，不通过修改位置/速度拖动物体。它属于仿真外部输入，不加入策略观测。方向键的0.2秒推球脉冲仍可与拖拽叠加。暂停时不会直接移动机器人；继续后才演算外力。

`check_mouse_force.py` 检查基于实际渲染像素的球/连杆/底盘拾取、平移施力与旋转力矩、16个物理子步回调、键盘叠加和松开/复位后的撤销。


## 原生窗口与性能

`view_ppo.py --single-arm` 现在调用 `view_native.py`，使用 MuJoCo 原生窗口、左右侧栏和鼠标交互。右侧展开 **Control**：`Ball_Fx/Fy/Fz_N`、`Paddle_Fx/Fy/Fz_N`、`Base_Fx/Fy/Fz_N` 分别施加世界坐标系下的持续外力，单位 N；设为0、按C、点Clear all或回合复位后清零。滑块是专门添加的扰动控制，不属于九个真实电机，不进入电机观测或策略。原生Ctrl鼠标拖拽仍可施力。

窗口默认仅同步状态 `viewer.sync(state_only=True)`，每个控制周期一次，避免重复复制约459万三角面的网格。模型、碰撞、D405输入、策略权重、480 Hz物理子步和30 Hz策略频率均保持原样。原生窗口自身独立渲染；左上角 **Control Hz** 表示实际控制循环频率，不是屏幕刷新FPS。

本机短时实测记录在 `native_before.json` 和 `native_after.json`：控制频率约9.24 Hz提升为29.90 Hz，同步总耗时约100.61 ms降为0.12 ms。右下角小窗宽度按4像素对齐，消除OpenGL RGB行对齐导致的白线。关闭窗口时等待原生渲染线程结束，避免同时销毁OpenGL上下文。

```bash
"$PY" view_ppo.py --single-arm
# 限时性能测量，完成后自动关闭窗口
"$PY" view_ppo.py --single-arm --profile-seconds 8 --profile-output native_profile.json
```

`view_custom.py` 保留此前自定义窗口作为回退；默认入口使用原生窗口。
