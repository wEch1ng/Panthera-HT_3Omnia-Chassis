# 电机与反馈约定

来源：用户提供《产品选型参数表最新（中文）》印刷第 4 页（5022），以及参考项目 sim/motor_limits.py（机械臂）。按模组输出轴计，速度从 rpm 转为 rad/s；不再乘减速比。

|位置|型号|额定/堵转力矩 N·m|额定/空载转速 rpm|额定/峰值电流 A|
|---|---|---|---|---|
|左、右、后轮|HTDW-5022-02-DNE|3.5 / 13|82 / 123|2 / 10|
|关节 1、4|HTDW-5036-02-DNE|6 / 21|50 / 75|2 / 10|
|关节 2、3|HTDW-6036-02-DNE|10 / 36|50 / 60|3 / 15|
|关节 5、6|HTDW-4438-30-NE|2 / 10|40 / 160|0.7 / 10|

5022：减速比22、额定24 V、30 W、质量322 g、输出编码器14 bit、标称控制频率3 kHz、响应140 μs。手册列力矩常数0.54 N·m/A；由于与模组电流/输出力矩口径尚未统一，未用其推导反馈力矩或电流限幅。

每个480 Hz物理子步应用参考项目的保守线性近似：`cap = 0.9 * stall * max(0, 1 - abs(velocity)/(0.9 * no_load_speed))`。超出90%额定转速时只允许反向制动力矩，不钳制真实状态。该曲线不是实测TN曲线，额定力矩并非允许无限时长的堵转力矩；热模型、驱动器电流控制和电池电压降尚未建模。模型仍用480 Hz积分，没有声称模拟3 kHz驱动器内部环路。

MotorFeedback 按左轮、右轮、后轮、关节1至6排列，提供输出轴位置、速度和电机反馈力矩，拼接为27维。仿真力矩使用gear=1的actuator_force，仅模拟理想电机输出反馈；不使用接触力、总广义力或偏置力作为力矩传感器。真机接入时需用驱动器反馈字段替代，并确认单位、符号、减速比口径和时间戳。理想反馈尚未添加量化、噪声、偏置、总线丢包和测量延迟。

当前四参数基线的伺服使用位置速度，已生成完整反馈观测接口，但力矩观测尚未参与策略决策。残差PPO任务已将27维电机反馈接入网络，运行入口为 `panthera train`；历史结果见 `reports/history/residual_run/`。默认原单臂策略保留原输入格式，不新增力矩特征。此前的20/20不能作为此电机模型和完整sim2real验收结论。
